# VibeCritic ✦

منصتك العربية لاكتشاف ما يستحق وقتك من الألعاب والأفلام والمسلسلات، عبر مراجعات نقدية واضحة وتجربة بحث سريعة.

## المزايا
- واجهة عربية RTL بهوية مستقلة وتصميم متجاوب.
- أقسام منفصلة للألعاب والأفلام والمسلسلات.
- مراجعات نقدية بدرجة من 10، مع نقاط القوة والضعف والحكم النهائي.
- بحث نصي سريع عبر Pagefind في جميع المراجعات المنشورة، دون خادم بحث منفصل.
- ترندات أسبوعية للأفلام والمسلسلات، وألعاب حديثة من RAWG أو IGDB.
- إنشاء مراجعة تفاعلية بمساعدة الذكاء الاصطناعي عبر صفحة «المراجع الذكي».
- نشر الموقع على Cloudflare Pages، وتوليد المحتوى عبر GitHub Actions.

## النشر وتوليد المراجعات
1. اربط المستودع بمشروع Cloudflare Pages، واجعل مجلد المشروع هو جذر المستودع وأمر البناء `npm run build` ومجلد الإخراج `dist`.
2. أضف مفاتيح الخدمات في GitHub → Settings → Secrets and variables → Actions. يلزم `TMDB_API_KEY`، ومصدر ألعاب واحد على الأقل: `RAWG_API_KEY` (الموصى به) أو `IGDB_CLIENT_ID` مع `IGDB_CLIENT_SECRET`.
3. أضف مفتاحاً واحداً على الأقل من مزودي الذكاء الاصطناعي: `GEMINI_API_KEY` أو `GROQ_API_KEY` أو `OPENROUTER_API_KEY` أو `OPENAI_API_KEY`.
4. اختر `AI_PROVIDER` اختيارياً بقيمة `gemini` أو `groq` أو `openrouter` أو `openai`. عند تركه فارغاً، تكون الأولوية لـ Gemini ثم Groq ثم OpenRouter ثم OpenAI، مع الانتقال إلى المزوّدات المتاحة عند فشل المزوّد المختار.
5. اختيارياً: أضف Repository Variables باسم `CF_AI_GATEWAY_ACCOUNT_ID` و`CF_AI_GATEWAY_ID` لتوجيه طلبات Gemini وGroq وOpenAI وOpenRouter عبر Cloudflare AI Gateway باستخدام مسارات المزود الأصلية. اترك المتغيرين فارغين للاتصال المباشر بالمزوّدات. يمكن تفعيل Cache Responses وسجلات البوابة وحدود الطلبات من لوحة Cloudflare؛ التخزين المؤقت يفيد أساساً عند تكرار الطلب نفسه، ولا يلغي تكلفة استدلال المزوّد ولا ينشئ رصيداً مجانياً.
6. يعمل Workflow باسم **Generate reviews and publish** تلقائياً كل 12 ساعة (03:17 و15:17 بتوقيت الجزائر)، وينشئ مقالاً واحداً كحد أقصى في التشغيل ومقالين يومياً. التشغيل اليدوي يخضع للسقف اليومي نفسه.

يمكن تخصيص `GAMES_WINDOW_DAYS` و`OPENAI_MODEL` و`GEMINI_MODEL` و`GROQ_MODEL` و`OPENROUTER_MODEL` من Repository Variables. مفاتيح المراجع التفاعلي `/api/review` تُضاف بشكل منفصل في إعدادات Cloudflare Pages → Variables and Secrets.

## التشغيل محلياً
```bash
npm install
npm run dev
```

## مصادر البيانات والإسناد
بيانات الأفلام والمسلسلات مقدمة عبر TMDb، وهذا المنتج غير معتمد أو مصادق عليه من TMDb. بيانات الألعاب مقدمة عبر RAWG، وقد يُستخدم IGDB كمصدر احتياطي. المراجعات المولّدة بالذكاء الاصطناعي موسومة بوضوح داخل الموقع، وينبغي التحقق من الادعاءات الواقعية قبل اعتمادها.
